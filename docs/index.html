Пошаговая инструкция ↗

  1. Добавьте фото

    Выберите снимок, на котором хорошо виден контур предмета. Для пробы подойдёт утка из редактора.

  2. Проверьте форму

    Поверните модель и подберите детализацию. Ещё один снимок сбоку поможет уточнить толщину.

  3. Скачайте ZIP

    В архиве лежат GLB со встроенной текстурой и файлы для OBJ.
